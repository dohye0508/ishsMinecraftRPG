# 기획팀 가이드

코드 수정 없이 `configs/` 폴더의 `.yml` 파일만 편집해 서버 콘텐츠(스폰·인증·맵 경계, 아이템, 도전과제, 도움말, 퀘스트, NPC 대화)를 변경하는 방법입니다.

---

## 🔄 작업 흐름

1. `configs/` 안의 파일을 수정합니다.
2. `configs/배포.bat`을 실행합니다. 변경된 파일만 서버 `plugins/`로 복사되며, 덮어쓰기 전 서버 파일은 `backup_config/sync_<날짜시간>/`에 백업됩니다.
   - 적용 범위만 확인하려면 `미리보기_배포.bat`을 사용합니다.
3. 게임에서 OP 권한으로 아래 명령을 입력합니다. (서버가 꺼져 있었다면 기동만 하면 됩니다)
   - `/bq reload` — 퀘스트·대화
   - `/설정리로드` — config·아이템·도전과제·도움말
4. 확인 후 Git에 반영합니다. (`git add configs` → `git commit` → `git push`)

서버 폴더의 파일을 직접 수정한 경우에는 `서버에서_가져오기.bat`으로 `configs/`에 먼저 반영합니다. 그렇지 않고 `배포.bat`을 실행하면 서버 쪽 수정 내용이 `configs/`의 내용으로 덮어써집니다. (백업은 남습니다)

폴더 구조와 스크립트 상세는 [configs/README.md](../configs/README.md)를 참고합니다.

## 📁 편집 대상

| 대상 | 파일 (`configs/` 기준) | 적용 |
|---|---|---|
| 스폰, 인증, 맵 경계, `/퀘스트` 표시 이름 | `ishsMinecraftRpg/config.yml` | `/설정리로드` |
| 커스텀 아이템 | `ishsMinecraftRpg/items.yml` | `/설정리로드` |
| 도전과제 | `ishsMinecraftRpg/achievements.yml` | `/설정리로드` |
| `/도움말` 문구 | `ishsMinecraftRpg/help.yml` | `/설정리로드` |
| 퀘스트 목표·보상, NPC 연결 | `BetonQuest/QuestPackages/default/main.yml` | `/bq reload` |
| NPC 대사·선택지 | `BetonQuest/QuestPackages/default/conversations/<이름>.yml` | `/bq reload` |
| 몬스터 | `MythicMobs/Mobs/*.yml` | `/mm reload` |
| NPC 위치·외형 | 게임 내 `/npc` 명령 (Citizens) | 즉시 저장 |

NPC 위치는 서버의 `Citizens/saves.yml`에 저장됩니다. 이 파일은 직접 수정하지 않으며(서버 종료 시 덮어씀), 소유자 정보가 포함되어 있어 Git에도 포함하지 않습니다.

## ⚙️ config.yml

모든 좌표는 블록 좌표(`F3` 화면의 정수 좌표)입니다.

```yaml
auth:
  enabled: true        # false: 인증 없이 입장 (맵 수정·테스트 시 사용)
  room: {x, y, z}      # 인증 대기소 (맵 경계 밖에 배치)
  lock-size: 15        # 인증 중 이동 가능 범위 (한 변 길이, 블록)

spawn:
  first: {x, y, z}     # 최초 스폰 = 월드 스폰 (/lobby, 부활 위치)

border:
  enabled: true        # false: 맵 경계 미사용
  corner1: {x, z}      # 영역의 대각선 꼭짓점 (순서 무관, 양 끝 블록 포함)
  corner2: {x, z}

quests:                # /퀘스트 표시 이름
  <오브젝티브 ID>: "<표시 이름>"
```

- `auth.enabled` 변경은 이미 접속 중인 플레이어에게는 적용되지 않고 다음 접속부터 적용됩니다.
- 맵 경계는 직사각형이며, 경계에 가까워지면 월드보더(파란 벽)가 표시되고 경계 밖으로는 이동할 수 없습니다. 텔레포트는 제한하지 않습니다.

## 🗡️ 커스텀 아이템 (items.yml)

```yaml
items:
  jasmine_flower:            # 아이템 ID
    material: AZURE_BLUET    # 재료 (영어 대문자)
    name: "&d자스민 꽃"
    lore:                    # 설명문 (한 줄 = 항목 하나)
      - "&7으깨어 상처에 바르면 통증이 가라앉는다."
    unbreakable: false
```

- 이름·설명에는 `&` 색상 코드를 사용할 수 있습니다. (`&c` 빨강, `&a` 연두, `&7` 회색 등)
- 지급: `/아이템지급 <플레이어> <아이템ID>`
- 효과는 아이템 ID에 코드가 연결되어 있습니다. 기존 6종(`demerit_card`, `wanil_staff`, `jasmine_flower`, `schema`, `changbong_spear`, `changbong_rod`)의 ID를 변경하면 효과가 사라집니다. ID별 효과는 [ITEM_LIST.md](ITEM_LIST.md)를 참고합니다.
- 새 ID를 추가하면 효과 없는 장식용 아이템이 생성됩니다. 효과가 필요한 경우 개발 측에 요청합니다.
- 이미 지급된 아이템은 변경되지 않으며, 이후 지급분부터 반영됩니다.
- 재료 이름이 잘못되면 서버 콘솔에 경고가 출력되고 해당 아이템은 생성되지 않습니다.

## 🏆 도전과제 (achievements.yml)

```yaml
achievements:
  diamond:                   # 도전과제 ID
    material: DIAMOND        # GUI 표시 아이템
    title: "진짜 보물 찾기"
    description: "깊은 곳에서 다이아몬드를 발견했습니다."
    popup: "..."             # (선택) 달성 알림 문구, 없으면 description
    show-in-gui: false       # (선택) /도전과제 목록에서 숨김
```

- 이름·설명을 수정하면 `/도전과제` GUI와 달성 알림에 함께 반영됩니다.
- 달성 조건은 ID에 코드가 연결되어 있습니다. ID를 변경하거나 새로 추가해도 달성 조건은 생기지 않으며, 조건 추가는 개발 측에 요청합니다.
- `join_club`, `stat_up`, `first_npc`는 현재 달성 처리 코드가 없어 항상 미달성으로 표시됩니다.

## 📖 도움말 (help.yml)

- `lines`: 전체 플레이어, `op-lines`: OP 추가 노출, `footer`: 마지막 줄.
- 한 줄이 목록 항목 하나이며 빈 줄은 `""`로 작성합니다. 줄 안의 큰따옴표는 `\"`로 이스케이프합니다.

## 📜 퀘스트와 NPC 추가

예시: NPC `slime_hunter`가 슬라임 5마리 처치를 의뢰하고, 보상으로 커스텀 아이템 `slime_jelly`를 지급하는 퀘스트.

### 1. 보상 아이템 정의 (items.yml)

```yaml
  slime_jelly:
    material: SLIME_BALL
    name: "&a말랑한 슬라임 젤리"
    lore:
      - "&7슬라임에게서 얻은 쫀득한 젤리."
    unbreakable: false
```

### 2. NPC 생성 (게임 내)

```text
/npc create 슬라임사냥꾼
/npc id
```

`/npc id`(선택한 NPC) 또는 `/npc list`로 ID를 확인합니다. 위치 이동은 `/npc tphere`, 스킨은 `/npc skin <닉네임>`, 시선 처리는 `/npc look`을 사용합니다.

> **ID 주의**: `main.yml`에는 NPC 19명이 `citizens 0~18`로 연결되어 있습니다. NPC가 없는 상태에서 처음 생성하는 NPC는 ID 0이 되어 `vice_principal`(교감)로 연결됩니다. 다음 중 하나를 선택합니다.
> - [ID 표](#기존-npc-id-표) 순서대로 NPC 19명을 먼저 생성한 뒤 20번째부터 신규 NPC를 생성합니다.
> - 신규 NPC를 먼저 생성하고 `main.yml`의 `npcs:` 번호를 실제 ID에 맞게 수정합니다. 하나의 ID를 두 키에 연결하면 안 됩니다.

### 3. 퀘스트·NPC 연결 (main.yml)

각 섹션의 기존 제목 아래에 항목을 추가합니다. (섹션을 중복 선언하지 않습니다)

```yaml
events:
  start_slime_quest: "folder slime_start_obj,slime_start_msg"
  slime_start_obj: "objective start slime_quest_obj"
  slime_start_msg: "command msg %player% &e[시스템] 새로운 퀘스트를 받았습니다! (슬라임 사냥꾼)"
  slime_quest_reward: "folder slime_msg,slime_give"
  slime_msg: "command msg %player% &a[시스템] 슬라임 사냥꾼의 퀘스트를 완료했습니다!"
  slime_give: "command 아이템지급 %player% slime_jelly"

objectives:
  slime_quest_obj: "mobkill SLIME 5 events:slime_quest_reward"

npcs:
  slime_hunter: "citizens 19"          # 2단계에서 확인한 ID

npc_conversations:
  slime_hunter: slime_hunter           # NPC 키: 대화 파일 이름
```

| 목표 유형 | 형식 |
|---|---|
| 몬스터 처치 | `mobkill <몹 이름> <마릿수> events:<완료 이벤트>` |
| 블록 채굴 | `block <블록 이름> -<개수> events:<완료 이벤트>` (개수 앞에 `-`) |
| 아이템 제작 | `craft <아이템> <개수> events:<완료 이벤트>` |

바닐라 아이템 보상은 `command give %player% emerald 3` 형식을 사용합니다.

### 4. 대화 파일 (conversations/slime_hunter.yml)

```yaml
conversations:
  slime_hunter:
    quester: "슬라임 사냥꾼"
    first: start
    NPC_options:
      start:
        text: "&a[슬라임 사냥꾼]&f 어서 와, 신입! 요즘 슬라임이 너무 불어났어. 좀 도와줄 수 있겠어?"
        pointers: quest1,q_no
      q1:
        text: "&a[슬라임 사냥꾼]&f 슬라임을 5마리만 처치해 줘. 도와주면 쫀득한 젤리를 줄게!"
        pointers: accept,q_no
      q_accept:
        text: "&a[슬라임 사냥꾼]&f 고마워! 부탁할게."
        events: start_slime_quest
    player_options:
      quest1:
        text: "네, 도와드릴게요!"
        pointers: q1
      accept:
        text: "슬라임 5마리, 맡겨 주세요."
        pointers: q_accept
      q_no:
        text: "지금은 어려워요."
```

- 파일 이름과 `main.yml`의 `npc_conversations` 값이 일치해야 합니다.
- `pointers`는 다음에 이어질 선택지의 이름이며, 철자가 틀리면 대화가 중단됩니다.
- `events:`에 지정한 이벤트는 해당 대사가 출력될 때 실행됩니다.

### 5. `/퀘스트` 표시 이름 (config.yml)

```yaml
quests:
  slime_quest_obj: "슬라임 사냥꾼 - 슬라임 사냥"
```

키는 `main.yml`의 오브젝티브 ID와 동일해야 합니다.

### 6. 적용

`배포.bat` 실행 후 게임에서 `/bq reload`, `/설정리로드`를 입력합니다. NPC를 우클릭해 대화·수락·처치·보상 지급 순으로 확인합니다.

## 🔧 문제 해결

| 증상 | 확인 사항 |
|---|---|
| `/설정리로드` 후 값이 바뀌지 않음 | YAML 들여쓰기, 콜론(`:`) 뒤 공백 1칸 |
| `/퀘스트`에 퀘스트가 표시되지 않음 | `config.yml`의 `quests` 키와 `main.yml` 오브젝티브 ID 일치 여부 |
| NPC 우클릭 시 반응 없음 | `main.yml`의 `citizens <ID>`와 실제 NPC ID 일치 여부, `/bq reload` 실행 여부 |
| 대화가 중간에 끊김 | `pointers` 이름이 `NPC_options`/`player_options`에 존재하는지 |
| BetonQuest 로딩 오류 | 서버 콘솔의 오류 메시지 (대부분 들여쓰기 문제) |
| 아이템이 생성되지 않음 | 서버 콘솔의 `[items.yml]` 경고 (재료 이름 오타) |
